# Farbatlas V10 Upgrade

Dieses Paket wird über die vorhandenen V09-Dateien im GitHub-Repository hochgeladen. `index.html` bleibt bestehen und wird beim Netlify-Build automatisch um die V10-Bildspeicherung ergänzt.

- Bilder werden einzeln verkleinert und gespeichert.
- Der Datensatz enthält nur Bildverweise.
- V10 verwendet neue Speicherbereiche und beeinflusst V09-Testdaten nicht.
